# 🎓 Student Performance & Engagement Dashboard (Power BI)

## 📌 Project Overview
This Power BI dashboard analyzes student engagement and academic performance using classroom activity metrics such as raised hands, resource visits, announcements view, and discussion participation.  
It also highlights the impact of absence days and parent satisfaction on student performance levels.

---

## 🎯 Objectives
- Track overall student engagement and participation
- Compare engagement metrics across performance classes (H, M, L)
- Identify how absence days affect student performance
- Analyze parent satisfaction impact on student outcomes
- Explore topic-wise engagement to find improvement areas
- Enable interactive filtering by demographic and academic attributes

---

## 🛠 Tools & Technologies Used
- Power BI
- Power Query (Data Cleaning & Transformation)
- DAX Measures

---

## 📈 Key KPIs Included
- **Total Students**
- **Avg Announcements View**
- **Avg Raised Hands**
- **Avg Visited Resources**
- **Avg Discussion Participation**

---

## 📊 Dashboard Visuals & Analysis
- Avg Raised Hands by Class (H / M / L)
- Avg Visited Resources by Class
- Avg Announcements View by Class
- Avg Discussion by Class
- Class Distribution by Total Students
- Absence Days vs Performance Class
- Parent School Satisfaction Impact (Yes/No)
- Topic-wise Student Engagement Analysis
- Slicers for filtering by:
  - Gender
  - Nationality
  - Topic
  - Semester
  - Stage ID

---

## 🔍 Key Insights (Summary)
- High-performing students show higher engagement in **RaisedHands** and **VisitedResources**
- Students with **higher absence days** mostly fall under the **Low performance** category
- Parent satisfaction marked as **"Good"** has more high-performing students
- Some topics show lower engagement, indicating the need for improvement
